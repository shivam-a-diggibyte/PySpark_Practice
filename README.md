# PySpark Practice

A structured collection of PySpark practice programs and hands-on
exercises covering Spark fundamentals, DataFrame operations, joins,
aggregations, window functions, complex data types, data loading, SCD,
reusable transformations, and Spark performance.

## Topics Covered

-   Spark Basics
-   Reading and Writing Data
-   DataFrame Operations
-   Joins
-   Aggregations
-   Window Functions
-   Array Datatypes
-   explode() Function
-   Struct and Nested Data
-   from_json() Function
-   User Defined Functions (UDFs)
-   Tables and Delta Concepts
-   Data Loading Patterns
-   Slowly Changing Dimensions (SCD)
-   Reusable Transformations
-   applyInPandas()
-   Testing PySpark Transformations
-   Partitions and Repartitioning
-   Shuffle
-   Data Skew
-   Broadcast Joins
-   Salting
-   Caching and Persistence
-   Adaptive Query Execution (AQE)
-   collect() and Driver Memory Considerations

## Tools & Technologies

-   Python
-   PySpark
-   Apache Spark
-   Spark SQL
-   Delta Lake
-   Parquet
-   CSV & JSON
-   Pytest

## Objective

This repository is used for learning and practicing PySpark through
simple, focused examples and hands-on implementations, progressing from
Spark fundamentals to advanced data-processing and performance concepts.

## 👨‍💻 Practice Approach

Each topic is organized into separate Python files to make the concepts
easy to understand, run, practice, and revisit.
