# PySpark Practice

A structured collection of PySpark practice programs and hands-on
exercises covering core Spark concepts, DataFrame operations, joins,
aggregations, window functions, and data ingestion.

## Topics Covered

-   Spark Basics
-   Reading CSV and JSON Data
-   DataFrame Operations
-   Joins
-   Aggregations
-   Window Functions
-   Working with Sample Data

## Tools & Technologies

-   Python
-   PySpark
-   Apache Spark
-   CSV & JSON

## Objective

This repository is used for learning and practicing PySpark through
simple, focused examples and hands-on implementations.

## 👨‍💻 Practice Approach

Each topic is organized into separate Python files to make the concepts
easy to understand, run, and revisit.
